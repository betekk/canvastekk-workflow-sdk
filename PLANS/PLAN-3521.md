## Technical Notes

Baseline SDK `0384812`. Maintain result-file layout `1.1.0` for `2.0.0`; it supplies workflow revision and run data needed to recover the exact requirement. Keep optional recorded limits in v2 until the later producer ticket proves reconstruction. Body shape puts `measurements` under each check and keeps the counts per subject. Identity and geometry are independent. Optional original file attribution requires a verified element.

Read check descriptors separately from nested measurement events so field order cannot associate a reading with the wrong check, and overview never loads all geometry. Leave the existing `0.x` and `1.x` compact contracts alone; require exact `1.0.0` or `2.0.0` for lossless reads. TypeScript publishes the same body schema and the paired manifest type; the file-staged streaming reader is the existing Python interface used by deployed consumers.

No writer defaults, workflow definitions, or deployed suggestion graphs change. The `.env.local` parity gate belongs to the later execution re-pin, not these additive reader changes.
